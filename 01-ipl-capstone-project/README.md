
# 🏏 IPL 2022 Capstone Project

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on IPL match data to
discover useful patterns and insights related to teams, matches, tosses,
venues, and match results.

The analysis is performed using Python, Pandas, Matplotlib, and Seaborn.

## 🎯 Objectives

- Explore the IPL match dataset.
- Analyze match and team performance.
- Identify teams with the highest number of wins.
- Analyze toss decisions and their relationship with match outcomes.
- Explore match-winning patterns.
- Visualize important findings using charts and graphs.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook
