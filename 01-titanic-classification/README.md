# 🚢 Titanic Classification

## 📌 Project Overview

This project applies different Machine Learning classification algorithms
to the Titanic dataset to predict passenger survival.

The project focuses on understanding and implementing different
classification algorithms and comparing their performance.

## 🤖 Algorithms Used

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Decision Tree
- Support Vector Machine (SVM)
- Cross Validation

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 🎯 Objective

To understand and implement different classification algorithms
using the Titanic dataset and evaluate their performance.

## 📈 Learning Outcomes

- Understanding classification problems
- Implementing different ML algorithms
- Training and testing ML models
- Evaluating model performance
- Comparing different classification techniques
