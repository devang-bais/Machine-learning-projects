# 🌲 Ensemble Learning

## 📌 Project Overview

This project demonstrates different Ensemble Learning techniques
using the Iris dataset.

## 🤖 Algorithms Used

- Stacking Classifier
- Random Forest
- AdaBoost
- Gradient Boosting
- XGBoost

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Seaborn
- Google Colab

## 🎯 Objective

To understand different ensemble learning techniques and
compare their classification performance.

## 📂 Notebook

- `EnsembleLearning.ipynb` — Complete Ensemble Learning implementation

## 📊 Techniques Covered

### Stacking
Combines multiple base models using a meta-learner.

### Random Forest
Uses multiple decision trees to improve prediction performance.

### AdaBoost
Combines weak learners sequentially to create a stronger model.

### Gradient Boosting
Builds models sequentially to reduce prediction errors.

### XGBoost
An optimized gradient boosting algorithm widely used for machine learning.
