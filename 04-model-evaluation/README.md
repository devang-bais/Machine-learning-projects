# 🔍 Model Evaluation & Hyperparameter Tuning

## 📌 Project Overview

This project demonstrates model evaluation and hyperparameter
tuning techniques using the Iris dataset.

## 🤖 Techniques Used

- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- GridSearchCV
- RandomizedSearchCV

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Seaborn
- Google Colab

## 🎯 Objective

To understand how hyperparameter tuning can be used to find
better model parameters and improve machine learning performance.

## 📊 Hyperparameter Tuning

### GridSearchCV

Tests different combinations of hyperparameters and identifies
the best performing combination using cross-validation.

### RandomizedSearchCV

Tests a selected number of random hyperparameter combinations
using cross-validation.

## 📂 Notebook

- `GridSearchCV.ipynb` — Complete implementation of GridSearchCV and RandomizedSearchCV
