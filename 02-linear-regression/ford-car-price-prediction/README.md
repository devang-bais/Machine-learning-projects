# 🚗 Ford Car Price Prediction using Linear Regression

## 📌 Project Overview

This project uses Linear Regression to predict the price of Ford cars based on different car-related features.

The project demonstrates the complete Machine Learning workflow, including data loading, data preprocessing, exploratory data analysis, feature selection, model training, and model evaluation.

## 🎯 Objectives

- Understand the Ford car price dataset
- Perform Exploratory Data Analysis (EDA)
- Preprocess the dataset
- Select relevant features
- Build a Linear Regression model
- Train and test the model
- Evaluate model performance
- Understand the relationship between car features and price

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📊 Machine Learning Algorithm

### Linear Regression

Linear Regression is used to model the relationship between input features and the target variable (car price).
